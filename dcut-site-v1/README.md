# DCUT Website V1

A Next.js + GSAP prototype for the DCUT archive site.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize

- `data/site.js`: brand copy and project/archive entries.
- `app/globals.css`: visual system, spacing, film styling, responsive layout.
- `components/FilmRoll.js`: scroll-linked reel and film-strip behavior.

## Next planned layer

Replace `data/site.js` with a CMS (Sanity is a good fit) so projects, featured work, artists, stories, events, and site settings can be edited from an admin UI without code changes.
